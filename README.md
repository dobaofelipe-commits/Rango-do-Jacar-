# Rango-do-Jacare-
O projeto Rango do Jacaré tem como objetivo avaliar lugares pra comer perto do campus. Assim novos alunos teriam mais facilidade em encontrar bons lugares para comer.

⚛️ Frontend Stack
Construído com React e Vite.

Tópicos abordados:

Components
Props
Hooks
State management
Forms
Routing
API requests
Project structure
Reusability
🖥️ Backend Stack
Construído com Node.js utilizando Express.

Tópicos abordados:

HTTP fundamentals
REST APIs
Routes
Controllers
Middleware
CRUD operations
Error handling
Simple architecture

🔧 Commit Convention
Use mensagens de commit simples e padronizadas.

Format
tipo: descrição curta

Examples
feat: create login page
fix: correct navbar responsive bug
docs: update installation guide
refactor: separate auth controller
test: add user route tests
chore: update dependencies
🌿 Branches
Para manter o projeto organizado e facilitar o trabalho em equipe, utilize branches para cada tipo de alteração.

Common
main → versão estável e pronta para produção
develop → branch de desenvolvimento e integração de novas funcionalidades
Convenção de Nomes
Utilize nomes curtos, claros e em inglês.

Format
tipo/nome-da-tarefa

Examples
feature/login-page
feature/student-dashboard
feature/api-auth

fix/navbar-mobile
fix/form-validation

docs/readme-update

refactor/user-service

test/auth-routes
